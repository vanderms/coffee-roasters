# CoffeeRoasters

## About the Project

- CoffeeRoasters is my implementation of a Frontend Mentor design.

- My main goal was to test the new Tailwind CSS version (v4).

## Comments

- I'm not entirely sure I liked Tailwind v4.

- Tailwind is still the best option for rapid prototyping and a decent choice for production.

- I had never used Husky before, but I enjoy not having to run Prettier manually. I intend to use it again.

- The problem with these design implementations is that, at a certain point, I start asking myself if I'm actually working in my free time. I don’t like that feeling. But sometimes, it can be fun.
